# Instructions for coding assistants

This file is read by Codex and similar tools. Read CLAUDE.md first; every rule in it applies to any assistant, Codex included.

Short version: data folders are never written; work on your own branch named by your first name; HANDOFF.md is read first and written last; no API keys in files; no attribution lines in code, docs or commits; no sentence in docs over 200 characters.
