# Figures from real projects

Drawn by the tool from Diana Golovanova's VASP calculations, shared with her consent.

- `CrSe_coplanar_noSOC_bands.png`: coplanar CrSe, non-SOC band run (031_bands_nbands120), -3 to 3 eV. The run is noncollinear without SOC, so spin is not a good label and one colour is used.
- `CrSe_coplanar_SOC_bands.png`: coplanar CrSe, SOC band run (2-bands), -3 to 3 eV.
- `CrSe_coplanar_SOC_wannier_vs_vasp.png`: the Wannier Hamiltonian of 3.1-wannier against the 2-bands VASP bands, preliminary comparison, mean error 0.040 meV within 1 eV of the Fermi level.
- `MnTe_SOC_bands.png`: MnTe, SOC band run (9.4-band), labels from the VASPKIT KLABELS file.

The demo tree in `demo/` is synthetic. These four figures are the real ones.
