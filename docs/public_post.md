# Public post (YouTube or LinkedIn)

Which of your old calculation folders actually support the claims in your paper, and what should you run next?
At the Open Scientific Intelligence Hackathon we built AltermagAgent, a free and open tool that reads VASP folder trees without changing them.
It rebuilds the order of the runs and groups them into branches by structure, magnetic realization and spin-orbit coupling, drawn like a git history.
For each branch it walks the physicist's six steps, from structure and symmetry to Wannier functions and transport, and marks each done, partial or missing.
On real CrSe data it found four branches, matched its computed magnetic space group with the author's own findsym result, and named the next calculation.
Published papers are shown in a separate section, never mixed with the evidence from the files.
